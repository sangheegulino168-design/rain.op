# SecQA —— 离线网络安全知识问答

RAG 方向小 agent：**BM25 检索 + 抽取式回答**，内置 24 条网络安全知识，
覆盖 Web 安全、系统加固、应急响应、网络防御、密码学等主题。
纯 Python 标准库实现，**无需 API Key，完全离线可运行**。

## 目录结构

```
agents/02-secqa/
├── secqa.py           # 主程序：分词 → BM25 检索 → 抽取式回答
├── kb.json            # 知识库：24 条安全问答（id / 标题 / 标签 / 正文）
├── requirements.txt   # 纯标准库，无第三方依赖
└── README.md          # 本文件
```

## 怎么跑

```bash
# 演示模式：自动跑 4 个示例问题
python secqa.py --demo

# 自由提问
python secqa.py --ask "什么是 SQL 注入？如何防御？"

# 取回更多候选知识块
python secqa.py --ask "钓鱼邮件怎么识别？" --topk 5

# 换自己的知识库（JSON 数组，每条含 id/title/tags/text）
python secqa.py --ask "..." --kb my_kb.json
```

## 示例输出

```
$ python secqa.py --ask "服务器中了勒索软件该怎么办？"

问题：服务器中了勒索软件该怎么办？

回答：
勒索软件典型特征是文件被批量加密并改后缀、桌面留下勒索信要求支付虚拟货币。
判断勒索家族并查是否有公开解密工具； [1]

引用：
  [1] kb-09《勒索软件应急》  tags: 恶意软件/应急  (BM25 得分 13.99)
```

问知识库之外的问题会如实拒绝，而不是胡编：

```
$ python secqa.py --ask "今天天气怎么样"

回答：
抱歉，知识库里没有找到与这个问题相关的内容。
换个问法试试，例如：什么是 SQL 注入？ / 如何防御 XSS？
```

## 原理

1. **分词**：中英混合——英文/数字按词切，中文按字二元切（如"注入"），
   简单但对短文本检索很有效。
2. **检索**：标准 BM25（k1=1.5, b=0.75）；建索引时标题加权 ×2 并混入标签，
   让"XSS 有哪几种类型"这类问题能命中标题含 XSS 的条目。
3. **回答**：抽取式——从最相关的知识块里挑与问题词重叠度最高的 2 个句子，
   拼成回答并标注 `[1][2]` 引用；得分不足首位 40% 的弱相关块会被过滤掉。
4. **无命中**：首位得分过低时直接说明知识库没有相关内容。

## 局限

- 抽取式回答，不是生成式：答案是原文句子的拼接，读起来不如 LLM 流畅。
- 知识库只有 24 条，覆盖面有限；可自行扩展 `kb.json`。
- 中文分词是字二元的近似方案，长句的语义理解能力弱。

## 可扩展的方向

- 换真正的中文分词（jieba）提升检索精度；
- 接本地小模型做生成式回答，BM25 只负责召回；
- 给知识库加上 CVE 编号、时间字段，支持"最近一年的高危漏洞"这类过滤问答。
